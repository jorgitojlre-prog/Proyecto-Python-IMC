
# Proyecto-Python-IMC

## Descripción del programa

Este proyecto consiste en una calculadora del Índice de Masa Corporal (IMC), desarrollada en Python como parte del bootcamp de Fundamentos de Python de U Camp.

El programa solicita el nombre, los apellidos, la edad, el peso en kilogramos y la estatura en metros.

Después calcula el IMC mediante la fórmula:

IMC = peso / (estatura ** 2)

Finalmente, presenta un reporte organizado con los datos del usuario y el resultado del IMC con dos decimales.

## Validación de datos

El programa incluye las siguientes validaciones:

- No permite dejar nombres ni apellidos vacíos.
- Verifica que la edad sea un número entero positivo.
- Verifica que el peso y la estatura sean números positivos.
- Muestra mensajes de error cuando se introducen datos incorrectos.
- Permite corregir los datos sin cerrar el programa.
- Utiliza try, except y while para controlar los errores.

## Instrucciones de ejecución

1. Tener instalado Python 3.
2. Descargar el archivo calculadora_imc.py desde este repositorio.
3. Abrirlo con Python IDLE o ejecutarlo desde la terminal con:

    python3 calculadora_imc.py

4. Ingresar los datos solicitados.
5. Revisar el reporte final del IMC.
